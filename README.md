# LUNA VOICE

A custom HTML/CSS/JS voice player for the LUNA VOICE project.

## Included
- Custom dark music player UI
- Uploaded WhatsApp voice audio converted to MP3
- Play / pause
- 10-second rewind and forward
- Progress scrubbing
- Repeat and shuffle controls
- Responsive mobile layout
- GitHub Pages deployment workflow

## Audio
The player loads:

`assets/song.mp3`

## GitHub Pages
The included workflow deploys the static site to GitHub Pages whenever changes are pushed to `main`.
